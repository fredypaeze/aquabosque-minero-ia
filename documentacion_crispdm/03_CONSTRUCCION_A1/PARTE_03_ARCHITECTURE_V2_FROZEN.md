# PARTE_03_ARCHITECTURE_V2_FROZEN - OBJETIVOS ESPECÍFICOS

## ARQUITECTURA NARRATIVA FINAL

### Lista de objetivos específicos
1. Construir un índice de riesgo ambiental combinado por municipio a partir de fuentes abiertas
2. Entrenar un clasificador interpretable que ordene los municipios en niveles de riesgo y explique el aporte de cada factor (SHAP)
3. Complementar la lectura nacional con capas de incendios (área quemada por dNBR en municipios seleccionados) y de alerta temprana a escala urbana (Bogotá)
4. Garantizar la reproducibilidad y la auditabilidad del producto en repositorio abierto

### Relación con el objetivo general
Los objetivos específicos respaldan directamente el objetivo general al:

1. **Construir el índice**: Permite ordenar los municipios por nivel de riesgo combinado
2. **Entrenar clasificador interpretable**: Proporciona explicación de factores dominantes
3. **Complementar con capas adicionales**: Añade profundidad al análisis territorial
4. **Garantizar reproducibilidad**: Cumple con el criterio transparente y auditable

### Medibilidad de cada objetivo
1. **Construir índice**: Se puede medir si se construye correctamente el índice compuesto
2. **Entrenar clasificador**: Se puede verificar si el modelo ordena correctamente y explica factores
3. **Complementar capas**: Se puede validar si se añaden correctamente las capas de incendios y alerta temprana
4. **Reproducibilidad**: Se puede verificar si el producto está en repositorio abierto

### Evidencia respaldando cada objetivo
1. **Construir índice**: Código fuente del proyecto, documentación técnica
2. **Entrenar clasificador**: Resultados del modelo, explicaciones SHAP
3. **Complementar capas**: Fuentes de datos de incendios, datos de alerta temprana
4. **Reproducibilidad**: Repositorio del proyecto, documentación de acceso

### Coherencia entre objetivos
Todos los objetivos están alineados con el objetivo general de proveer una herramienta de priorización del riesgo ambiental territorial con criterio transparente y auditable.
