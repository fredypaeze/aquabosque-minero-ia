# PARTE_12_ARCHITECTURE_V2_FROZEN - RIESGOS Y LIMITACIONES INICIALES

## ARQUITECTURA NARRATIVA FINAL

### Riesgos técnicos
- Fallo en la integración de datos heterogéneos de múltiples fuentes
- Problemas de escalabilidad en el procesamiento de grandes volúmenes de datos
- Fallo en el entrenamiento de modelos interpretables con alta complejidad
- Limitaciones en la calidad de datos de algunas fuentes

### Limitaciones del enfoque
- Enfoque exclusivo en municipios, excluyendo otros niveles de análisis
- Separación entre priorización nacional y alerta temprana urbana
- Enfoque basado en datos abiertos, limitando la profundidad de análisis

### Limitaciones de datos
- Disponibilidad temporal limitada de algunos conjuntos de datos
- Calidad variable de datos provenientes de diferentes fuentes
- Cobertura geográfica incompleta en ciertas regiones
- Actualización periódica inconsistente de algunos datos

### Limitaciones de alcance
- Exclusión de monitoreo satelital en tiempo real
- Exclusión de otros tipos de análisis ambientales
- Dependencia de fuentes externas que pueden cambiar o dejar de estar disponibles
