# PARTE_08_ARCHITECTURE_V2_FROZEN - FUENTES DE DATOS

## ARQUITECTURA NARRATIVA FINAL

### Fuentes oficiales identificadas
ANM, IDEAM, NASA, IDIGER, y otras instituciones gubernamentales y científicas que proporcionan datos ambientales y geoespaciales.

### Fuentes de datos geoespaciales
Datos geoespaciales de municipios, zonas protegidas, infraestructura y características físicas del territorio.

### Fuentes de datos históricos
Series temporales de datos ambientales, registros de eventos ambientales como desastres naturales, y datos de uso del suelo históricos.

### Fuentes de datos actualizadas periódicamente
Datos meteorológicos y climáticos, datos de minería y actividades industriales, registros de deforestación y cambio de uso del suelo.

### Fuentes de datos cercanas al tiempo real
Datos de monitoreo satelital, datos de alertas tempranas, sensores ambientales, y sistemas de vigilancia de incendios forestales.
