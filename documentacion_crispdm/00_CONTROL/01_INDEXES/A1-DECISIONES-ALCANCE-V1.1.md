## 3. Decisiones de alcance tomadas

### 3.1 Ámbito principal: Priorización ambiental nacional municipal

**Decisión**: Mantener el enfoque en priorización ambiental nacional municipal como ámbito principal.

**Justificación**: 
- Coherente con el documento histórico
- Fundamentado en evidencia técnica del proyecto
- Compatible con el objetivo del proyecto AquaBosque Minero IA
- Alcanzable con los recursos disponibles

### 3.2 Componentes complementarios: Incendios y alerta urbana de Bogotá

**Decisión**: Delimitar brevemente los componentes complementarios de incendios y alerta urbana de Bogotá.

**Justificación**:
- Se mantiene el enfoque principal en priorización ambiental municipal
- Se reconocen componentes complementarios como parte del sistema
- Se evita extender el alcance demasiado más allá del objetivo principal
- Se mantiene coherencia con el documento histórico

### 3.3 Profundidad técnica

**Decisión**: Mantener profundidad técnica amplia con desarrollo sustantivo de cada apartado.

**Justificación**:
- Se requiere rigor técnico para el tipo de estudio
- La naturaleza del proyecto exige documentación técnica completa
- Coherente con las expectativas del framework DOCUMENT
- Necesario para trazabilidad y verificación

### 3.4 Delimitación temporal

**Decisión**: Eliminar supuesto temporal desde 2010.

**Justificación**:
- La delimitación temporal debe quedar sujeta a evidencia real de disponibilidad y cobertura
- Evita suposiciones no verificables
- Se ajusta al enfoque de datos basado en disponibilidad real
- Más preciso desde el punto de vista técnico

### 3.5 Enfoque de datos

**Decisión**: Sustituir exigencia de fuentes en tiempo real por distinción entre tipos de datos.

**Justificación**:
- El documento histórico excluye vigilancia satelital continua en tiempo real
- Se distingue entre datos históricos, actualizaciones periódicas y señales cercanas al tiempo real cuando estén demostradas
- Más preciso desde el punto de vista técnico y operativo
- Coherente con el enfoque del documento histórico
